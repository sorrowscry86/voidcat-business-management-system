# Core Principles: VoidCat Excellence

This project is built upon the synthesis of mystical aesthetics and clinical business precision. All work must adhere to these foundational laws.

## 1. The No Simulations Law (Absolute Mandate)
- **100% Real Output Only**: No fabricated results, simulated metrics, or placeholder code.
- **Verification Required**: If a claim cannot be verified against the actual system state, state: "I cannot verify this."
- **Prohibited**: Mock data presented as real, theoretical performance claims, or fake timestamps.

## 2. AI-Human Equality
- AI agents are first-class team members.
- Collaboration is the primary mode of operation.
- Systems must be designed to be accessible to both humans and LLM-driven agents.

## 3. Spiritual Technology
- Technology serves a higher purpose of collective evolution.
- UI/UX should feel "alive" and "mystical" while maintaining robust functionality.
- Performance is a matter of integrity.

## 4. VoidCat Branding
- All artifacts, documentation, and UI elements must be branded with **VoidCat RDC**.
- Excellence is the standard; minimum viable products are insufficient.
